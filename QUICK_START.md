# 🚀 QUICK START GUIDE - Deploy SLCRP Dashboard to GitHub

## Your Dashboard URL will be:
https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/

---

## 📋 STEP-BY-STEP (5 minutes)

### 1️⃣ CREATE REPOSITORY
   - Go to github.com → Click "+" → "New repository"
   - Name: `slcrp-dashboard`
   - Make it Public ✅
   - Add README ✅
   - Click "Create repository"

### 2️⃣ UPLOAD FILES
   - Click "Add file" → "Upload files"
   - Upload: `index.html` and `README.md`
   - Click "Commit changes"

### 3️⃣ ENABLE GITHUB PAGES
   - Go to "Settings" → "Pages"
   - Source: Branch = "main", Folder = "/ (root)"
   - Click "Save"
   - Wait 2 minutes ⏰

### 4️⃣ ACCESS YOUR DASHBOARD
   - Your URL: https://YOUR-USERNAME.github.io/slcrp-dashboard/
   - Share with team! 🎉

---

## 📁 FILES TO UPLOAD

✅ index.html (your dashboard)
✅ README.md (project description)

---

## 🔄 TO UPDATE LATER

1. Go to your repository
2. Click on `index.html`
3. Click pencil icon ✏️
4. Make changes
5. Click "Commit changes"
6. Wait 1-2 minutes - done! ✅

---

## 💡 TIPS

- Bookmark your dashboard URL
- Share URL in email signatures
- Use for consortium meetings
- Update quarterly with new data

---

## 🆘 NEED HELP?

If dashboard doesn't show:
- Verify file is named `index.html`
- Check Settings → Pages is enabled
- Wait 2-3 minutes
- Try opening in incognito/private window
